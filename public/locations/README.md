# Location data

Contains information from the Countries States Cities Database by Darshan Gada and contributors:
https://github.com/dr5hn/countries-states-cities-database

The database and these compact, country-split extracts are available under the Open Database License (ODbL) 1.0:
https://opendatacommons.org/licenses/odbl/1-0/

Retrieved 2026-11-12. Country metadata comes from json/countries.json; city records come from the json-cities.json.gz release asset.
Each city array contains [name, latitude, longitude, state/region]. Records are alphabetized and retain valid coordinates. Files in cities/ are grouped by ISO2 country code. countries.json provides country names, ISO codes, coordinates and city counts. No API keys or external requests are needed at runtime.
