# PRVLG ? The Origin Project

Frontend-only globe experience with country/city selection, a personal celestial emblem, and garment previews.

Run `pnpm dev`, or `pnpm build` and `pnpm start`. No backend, database, authentication service, or email credentials are required.

Country/city data and garment assets are served as local static files. Journey selections and profile details remain in browser memory for the current session. Dashboard pages are an empty frontend preview; settings are saved only in this browser. Contact submission and account security actions are unavailable.

The globe always stays fully visible. Expand globe opens a full-screen explorer with plus/minus controls and zoom up to the largest complete circle that fits the screen. The curved PRVLG logo stays facing the viewer when selected locations rotate the geography.
